Entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) competition on [make.fun](https://make.fun/).

## What it does

`main.ts` (Node 22, stdlib only) writes a single one-line comedy joke of at most 280 characters to `/output/entry.txt`. The joke is fixed, deterministic text — the program writes the same bytes on every run.

## The joke

> My grandfather kept his hearing aid in the same drawer as his wedding ring, and every morning he chose which one to wear based on whether Grandma was talking or just waiting for him to agree — after fifty years, he still hasn't worked out which one costs him more.

(264 characters, one line.)

## Run it

```sh
node main.ts
cat /output/entry.txt
```
